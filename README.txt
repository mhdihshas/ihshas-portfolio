IHSHAS PORTFOLIO WEBSITE
========================

Files
-----
index.html   - Home, About, and Skills
work.html    - Projects, Experience, and Contact
styles.css   - Website design and responsive layout
script.js    - Animations, mobile menu, counters, and contact form
assets/      - Profile image and downloadable CV

How to open
-----------
1. Open this folder in Visual Studio Code.
2. Double-click index.html, or install the "Live Server" extension.
3. With Live Server installed, right-click index.html and choose "Open with Live Server".

How to edit
-----------
- Personal text: index.html and work.html
- Colours and design: styles.css
- Animations and contact form: script.js
- Profile image: replace assets/profile.webp
- CV file: replace assets/ANWARKHAN_MOHAMED_IHSHAS_CV.docx

Publishing options
------------------
You can publish this static website for free using GitHub Pages, Netlify, or Cloudflare Pages.

Important
---------
The contact form does not need a backend. It opens the visitor's default email application.
